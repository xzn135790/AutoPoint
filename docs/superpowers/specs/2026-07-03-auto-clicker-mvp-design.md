# 自动连点器 MVP 设计

## 范围

本次实现一个适配红米 Android 13+ 的本地可运行自动连点器 MVP。目标是先完成核心闭环：用户能创建多套连点方案，配置点击或滑动步骤，设置每步延时、持续时间、坐标随机偏差和循环次数，并通过无障碍服务执行。

不做账号、云同步、广告、付费、远程控制、脚本市场等商用扩展。

## 功能

- 方案管理：创建、复制、删除、启用多套方案。
- 步骤编辑：支持点击步骤和滑动步骤。
- 延时控制：每一步可配置执行前延时。
- 位置模糊：点击点和滑动起止点支持随机偏差范围。
- 循环执行：支持有限次数循环和持续运行。
- 权限引导：提供无障碍服务和悬浮窗权限入口。
- 悬浮控制：提供开始、暂停、停止的悬浮面板，方便在其他应用上执行。

## 界面

使用原生 Android XML + Material Components。主界面采用深浅对比明确的现代工具风格：

- 顶部显示当前方案、执行状态和权限状态。
- 中间显示步骤时间线，每个步骤用紧凑卡片展示类型、延时、坐标、偏差。
- 底部提供新增点击、新增滑动、保存、启动入口。
- 编辑弹窗使用表单控件配置坐标、时长、延时和随机偏差。

界面优先保证手机竖屏可用，按钮尺寸适合单手操作。

## 架构

- `MainActivity`：主界面、权限入口、方案编辑。
- `AutoClickAccessibilityService`：通过 `dispatchGesture` 执行点击和滑动。
- `FloatingControlService`：悬浮控制条，负责开始、暂停、停止。
- `ClickProfileStore`：用 `SharedPreferences` 持久化方案 JSON。
- `ClickProfile` / `ClickStep`：方案和步骤数据模型。
- `AutoClickEngine`：执行调度、延时、循环和随机偏差计算。

## 数据模型

方案包含：id、名称、循环次数、是否无限循环、步骤列表。

点击步骤包含：x、y、执行前延时、点击持续时间、随机偏差半径。

滑动步骤包含：起点 x/y、终点 x/y、执行前延时、滑动持续时间、随机偏差半径。

## 错误处理

- 无障碍服务未开启时不执行，提示用户去系统设置开启。
- 悬浮窗权限未开启时不启动悬浮服务，提示用户授权。
- 步骤为空时禁止启动。
- 坐标或时间输入非法时在表单内提示。
- 执行过程中服务断开时停止任务并更新状态。

## 测试

- 构建验证：运行 `:app:assembleDebug`。
- 逻辑验证：补充基础单元测试，覆盖随机偏差范围、步骤序列化、循环边界。
- 手动验证：安装到 Android 13+ 设备，检查无障碍权限、悬浮窗权限、点击和滑动执行。

## 约束

Android 13+ 对无障碍服务权限和后台悬浮窗较严格，真实执行依赖用户手动开启权限。应用只做本地自动化，不绕过系统权限。
